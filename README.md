## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Track all Scrivener projects with word count and deadline goals |
| **Chapter Tracker** | Log chapter draft status and revision notes per chapter |
| **Research Notes** | Organize research materials linked to your writing projects |
| **Writing Goals** | Set and track daily and project word count targets |
